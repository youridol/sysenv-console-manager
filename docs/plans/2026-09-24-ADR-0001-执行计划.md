`cargo test --test iperf3_contract`、以及 T2 的最小复现。

`npm run build`/`lint`、脚本隔离实证。

**批次 3（一般/建议）**：T9–T16。每完成一组执行对应的编译与测试门禁。

**收尾门禁**：

    npm run build
    npm run lint
    cd datasource && cargo check --all-targets && cargo test
    cd src-tauri && cargo check --all-targets
    <测试二进制> --test-threads=4
    bash scripts/test-lib.sh
