# 架构决策记录（ADR）索引

本目录存放 SECM 的架构决策记录。采用 MADR 精简形式：状态、日期、背景、决策、后果、被否决的方案、参考。

约定：

- 一份 ADR 只承载决策与理由，不重复缺陷证据；证据保存在对应审查报告与 `CHANGELOG.md` 条目中。
- 文件命名：`ADR-NNNN-<中文简述>.md`，编号单调递增且不复用。
- 决策被推翻时不删除原记录，改为把状态置为「已取代」并指向新 ADR。
